# README artwork

`banner.svg` is original vector artwork for BlurGo, an abstract illustration rather than a screenshot of the plugin.

The four `source-*.png` files are unmodified OBS output from the generated test pattern in the [0.1.0 acceptance record](../qa/0.1.0-manual-signoff.md), captured on 2026-09-02 with OBS 32.2.2 / Direct3D 11. Gaussian and Box use radius 12 and two passes; Pixelate uses block size 16; mix is 100%. Transparent borders are preserved. These are synthetic-source examples, not desktop or game captures.

The artwork and generated-pattern captures use the repository's [GPL-2.0-or-later license](../../LICENSE).
