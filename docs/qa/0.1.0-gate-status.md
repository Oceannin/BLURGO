# BlurGo 0.1.0 release gate status

Status date: 2026-09-01  
Decision: **not ready to tag**

This matrix records the evidence for the 0.1.0 alpha candidate. A checked item is supported by the linked CI or runtime report. An unchecked item is deliberately not inferred from compilation or synthetic-source coverage.

## Automated gates

- [x] Format workflow passes.
- [x] Windows x64 build and settings tests pass.
- [x] macOS Universal build and settings tests pass.
- [x] Ubuntu 24.04 x86_64 build and settings tests pass.
- [x] Packages and SHA-256 checksums are produced.
- [ ] The packaging-document changes on top of CI run 33472409651 pass a fresh matrix and artifact inspection.

## Windows OBS runtime

- [x] Plugin loads on OBS 31.1.1 and 32.2.2 without a BlurGo warning or error.
- [x] Gaussian, Box, and Pixelate render on a source.
- [x] Nested-scene workflow renders the complete scene.
- [x] Settings update live through the OBS API and persist after restart.
- [x] Transparent edges, zero-mix passthrough, and zero-radius passthrough behave correctly.
- [x] Source resize/deletion, filter reorder/removal, scene switches, restart, and shutdown do not crash.
- [x] P010 / Rec. 2100 PQ renders without a black or washed-out generated test frame.
- [x] Display capture renders all modes after the harness selects and makes the monitor source visible; private frames are deleted.
- [ ] Representative window and real-game capture.
- [ ] Forced GPU loss/reinitialization recovery.

## Performance and stability

- [x] Baseline and radius-12/two-pass Gaussian frame times measured.
- [x] 1080p60 HDR, 1440p60 SDR, and 4K60 SDR runs completed.
- [x] Thirty-minute 1080p60 scene-switch stress run shows no increasing memory trend.
- [x] Conservative starting presets are documented in the README.

## Cross-platform and release hygiene

- [ ] Native runtime QA on macOS.
- [ ] Native runtime QA on Ubuntu.
- [x] Version and package metadata are aligned at 0.1.0 in the untagged candidate.
- [x] Requirements, installation, known limitations, security policy, license, and draft release notes are present.
- [ ] Maintainer manual QA sign-off.
- [ ] Public `v0.1.0` tag and GitHub Release.
