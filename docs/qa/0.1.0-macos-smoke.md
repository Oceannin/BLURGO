The macOS job installed the Universal PKG into the current-user Installer domain, asserted the resulting plugin bundle under `~/Library/Application Support/obs-studio/plugins`, launched a real OBS process, and ran `tools/obs-smoke.py` through OBS WebSocket. Generated test-pattern frames, the OBS log, and `report.json` are retained in the CI artifact.

## Environment

- GitHub-hosted Apple Silicon runner: virtual Apple M1, three cores, 7 GB memory.
- macOS Sequoia 15.7.7, build 24G720; OBS ran natively without Rosetta.
- OBS Studio 32.2.1 and obs-websocket 5.7.4.
- OpenGL 4.1 / GLSL 4.10 on Apple Software Renderer.
- 1280x720 at 60 FPS, NV12, Rec. 709, Partial range.

## Functional results

- OBS discovered the plugin from the installed PKG, loaded `blurgo`, and logged `[blurgo] loaded successfully (version 0.1.0)`.
- Both bundled effects compiled and all three modes rendered without a BlurGo warning or error.
- Gaussian, Box, and Pixelate materially changed the source image and retained a meaningful alpha range.
- Mix 0% and radius 0 produced pixel-identical passthrough output.
- A BlurGo filter on a nested scene materially changed the complete scene composite.
- Live settings, source resize, filter reorder/removal, 20 scene switches, and disposable-source deletion completed without a BlurGo failure or crash.
- OBS unloaded the plugin normally and reported zero memory leaks. The generated original, three mode results, and nested-scene result were also inspected visually.

The nested-scene Gaussian result had a mean absolute RGB difference of 103.1947 and an alpha range of 0-255. The resized-source result differed by 33.1486. Both passthrough checks had a difference of exactly 0.0.

## Performance context

OBS reported 201.5203 ms average frame-render time in the unfiltered sample and 251.7707 ms with a radius-12, two-pass Gaussian filter, a delta of 50.2504 ms. The virtual runner used Apple's software renderer and could not sustain the requested 60 FPS, so these values validate execution and failure handling only; they are not a physical-Mac GPU benchmark.

## Scope and remaining gates

This run closes native Apple Silicon macOS source/nested-scene rendering and packaged-plugin discovery for the 0.1.0 candidate. It does not cover a physical Mac GPU, macOS capture sources, signing/notarization, restart persistence, or forced GPU reinitialization. See [the 0.1.0 gate status](0.1.0-gate-status.md) for the release decision.
