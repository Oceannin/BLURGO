## OBS acceptance check

- [x] Back up the scene collection, start OBS, and open the current log. (A disposable portable profile was used instead of the maintainer's production collection.)
- [x] Add BlurGo under **Effect Filters** on a visible source and confirm the unfiltered original is correct when the filter is hidden.
- [x] Enable Gaussian, adjust radius and passes, and confirm the preview responds immediately.
- [x] Switch to Box, adjust radius and passes, and confirm the preview responds immediately.
- [x] Switch to Pixelate, adjust block size, and confirm the preview responds immediately.
- [x] Change mix from 100% to 0% and confirm 0% is a visual passthrough.
- [x] Put the source inside another scene, add that scene as a source, and confirm BlurGo blurs the complete nested scene.
- [x] Switch scenes, resize the source, reorder/remove/re-add the filter, and confirm OBS remains stable.
- [x] Restart OBS and confirm the saved mode and values are restored.
- [x] Confirm the preview is not black or washed out and the OBS log contains no BlurGo warning or error.
