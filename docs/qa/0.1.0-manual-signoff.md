Use this short acceptance check after the automated gates in [the 0.1.0 gate status](0.1.0-gate-status.md) are green. Run it on a disposable OBS profile or a backed-up scene collection. An image, Window Capture, or Display Capture source is sufficient; a game is not required.

## OBS acceptance check

- [ ] Back up the scene collection, start OBS, and open the current log.
- [ ] Add BlurGo under **Effect Filters** on a visible source and confirm the unfiltered original is correct when the filter is hidden.
- [ ] Enable Gaussian, adjust radius and passes, and confirm the preview responds immediately.
- [ ] Switch to Box, adjust radius and passes, and confirm the preview responds immediately.
- [ ] Switch to Pixelate, adjust block size, and confirm the preview responds immediately.
- [ ] Change mix from 100% to 0% and confirm 0% is a visual passthrough.
- [ ] Put the source inside another scene, add that scene as a source, and confirm BlurGo blurs the complete nested scene.
- [ ] Switch scenes, resize the source, reorder/remove/re-add the filter, and confirm OBS remains stable.
- [ ] Restart OBS and confirm the saved mode and values are restored.
- [ ] Confirm the preview is not black or washed out and the OBS log contains no BlurGo warning or error.

## Optional post-alpha qualification

The Game Capture harness and forced GPU-loss resilience exercise remain available for later compatibility work. Neither is a blocking requirement for 0.1.0. Use only an authorized game for Game Capture, and perform graphics-device resets only in a disposable lab environment where the tester independently owns the recovery method.
