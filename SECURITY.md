# Security Policy

## Supported versions

Security fixes are provided for the latest published BlurGo release. Pre-release builds may receive fixes without backwards-compatibility guarantees.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability** action in the repository Security tab. Include affected versions, reproduction details, impact, and any proposed mitigation.

The maintainers will acknowledge a complete report within seven days and coordinate disclosure after a fix is available. Please avoid sharing crash dumps or OBS logs publicly when they contain stream keys, file paths, source URLs, or other sensitive data.
